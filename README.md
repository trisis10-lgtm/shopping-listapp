# 🛒 Shopping List App

A simple and elegant shopping list web application built with vanilla HTML, CSS, and JavaScript.

## Features

- ✨ Clean, modern UI with gradient background
- ➕ Add items to your shopping list
- ✅ Check off completed items
- 🗑️ Delete items
- 💾 Persistent storage using localStorage
- 📊 Item statistics (total and completed count)
- 🔒 XSS protection
- 📱 Responsive design

## How to Use

1. Open `shopping-list.html` in your web browser
2. Type an item name in the input field
3. Click "추가" (Add) button or press Enter
4. Check the checkbox to mark items as completed
5. Click "삭제" (Delete) to remove items

## Features in Detail

### Add Items
Simply type the item name and click the add button or press Enter to add it to your list.

### Mark as Complete
Click the checkbox next to an item to mark it as done. Completed items will appear with strikethrough text and reduced opacity.

### Delete Items
Click the delete button to remove an item from your list.

### Statistics
The app displays the total number of items and how many are completed.

### Persistent Storage
Your shopping list is automatically saved to your browser's localStorage, so your items will persist even after you close and reopen the page.

## Technology Stack

- **HTML5** - Structure
- **CSS3** - Styling with modern features like flexbox and gradients
- **Vanilla JavaScript** - Functionality (no frameworks)

## Browser Support

Works on all modern browsers that support:
- localStorage API
- CSS Flexbox
- ES6 JavaScript

```bash
git clone https://github.com/trisis10-lgtm/shopping-listapp.git

```

Then open `shopping-list.html` with your preferred browser.
